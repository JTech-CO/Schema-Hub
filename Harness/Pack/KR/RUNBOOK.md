# RUNBOOK.md — 런북 (증상 → 원인 → 조치)

> 아래는 어떤 프로젝트에나 흔한 일반 행이다. 프로젝트 고유 이슈는 처음 겪을 때 임시 처치 후 `PROGRESS.md`에 기록하고, 반복되면 여기 행으로 승격한다. 불변식 관련 증상은 조치에 INV-n를 함께 적는다.

| # | 증상 | 흔한 원인 | 조치 |
|---|---|---|---|
| 1 | 환경/의존성 설치 실패 | 버전 불일치, 잘못된 소스/인덱스, 락파일 깨짐, 플랫폼 차이 | 환경 가이드대로 재설치, 버전·소스 고정, 락파일 재생성 |
| 2 | 빌드/타입체크 실패 | 타입 불일치, 설정·경로 오류, 의존성 누락 | 에러 위치부터 좁혀 수정 |
| 3 | 테스트 불안정(flaky) | 시간·순서·외부 의존, 시드 미고정 | 시드 고정, 외부 의존 격리(mock), 결정론 확보 |
| 4 | 정합성(parity) 실패 (INV-5) | 두 구현의 입력 레이아웃·정규화·순서 차이 | 단일 기준 문서로 양측 정렬, 항목별 출력 비교로 어긋난 지점 특정 |
| 5 | "돌지만 효과 없음" (핵심 기능) | 핵심 신호 누락·스케일 오류, 전제 미충족, 입력 마스킹 누락 | 신호·전제부터, 초소형 케이스 과적합(sanity)으로 로직 검증 |
| 6 | 수치 발산/폭주(NaN 등) | 스케일 과대, 누적 오차, 식 오류 | 스케일·정규화 점검, 클리핑, 핵심 식 재검토 |
| 7 | 처리 느림 / 자원 활용 낮음 | 직렬 병목, 불필요 반복, 배치 미적용 | 병렬화/벡터화, 배치 처리, 핫스팟 프로파일링 |
| 8 | 경계 위반 lint 에러 (INV-3) | 모듈 간 금지된 상호 import | 경계 준수, 공유는 정해진 공용 계층만 |
| 9 | 외부 연동이 갑자기 깨짐 | 대상 API/DOM/스키마 변경 | 계약 파일 한 곳만 갱신(다른 파일 수정 금지), 변경분 기록 |
| 10 | 환경별 동작 차이(로컬↔CI↔배포) | 환경변수·경로·버전·권한 차이 | 환경 동등성 확보, env/시크릿·경로·버전 일치 점검 |
| 11 | 통신/연결 실패(CORS·WS·프록시 등) | 출처 허용 누락, 경로 불일치, 프록시 설정 | 허용 출처·경로·프록시 설정 점검, 양측 로그 대조 |
| {{n}} | {{프로젝트 고유 증상}} | {{...}} | {{...}} |

## 행 추가 규칙
같은 이슈를 2회 이상 겪으면 행으로 승격. 형식: 증상(관측 가능) / 가장 흔한 원인 순 / 최소 조치. 불변식 관련이면 INV-n 병기.
