# GLOSSARY.md — Shared Vocabulary

> Keeps the agent and the human using the same word for the same thing. A guard against vocabulary drift across sessions. Add project-specific terms.

| Term | Definition |
|---|---|
| DoR (Definition of Ready) | A phase's entry condition; must be met before work can start |
| DoD (Definition of Done) | A phase's completion gates; all must be met to be done |
| Invariant | A never-violate rule; a single violation blocks passing (`INVARIANTS.md`) |
| Parity | Two implementations of the same logic produce identical output for identical input |
| Gate | A measurable pass/fail criterion |
| Evidence | The command and output that justify a gate passing |
